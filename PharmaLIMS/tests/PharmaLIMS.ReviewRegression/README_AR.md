100 حالة من فرع المبرمج، و58 حالة إضافية/منقولة من 261، بينها حالات متداخلة عمدًا.

```powershell
dotnet run --project tests/PharmaLIMS.ReviewRegression/PharmaLIMS.ReviewRegression.csproj --configuration Release
```

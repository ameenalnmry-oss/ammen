## ما نُفذ من تحقق هنا

اجتازت مجموعة Python **348 اختبارًا دون فشل أو تخطٍّ**: 311 اختبارًا قائمًا و37 اختبارًا
مصدريًا جديدًا. عُدلت بعض تأكيدات الاختبارات القائمة لتتبع إصدار 260 وعدد الترحيلات
الجديد ومواقع المنطق المشترك وأسماء SQL؛ لم تُحذف اختبارات قائمة ولم تُعلّم بالتخطي.

هذه فحوص للمصدر وعقود الربط والنشر وليست تنفيذًا لـC# أو SQL.
تشمل الفحوص النهائية كذلك تحليل XML/XAML/JSON وربط أحداث الواجهات والتحقق من
بيانات الإصدار وبصمات المصدر والترحيلات عبر `scripts/validate_project.py`.

تمت مقارنة ملفات SQL الأصلية مباشرة بالملف المرفوع:
**قاعدة الأساس والترحيلات السابقة، 76 ملفًا، لم يتغير أي منها**.
أضيفت ترحيلة واحدة، فأصبح البيان يضم قاعدة أساس واحدة و76 ترحيلة.
لم يتم تغيير إصدارات حزم NuGet أو الادعاء بإجراء فحص ثغرات حديث عبر الإنترنت.

## اختبارات جاهزة لكنها غير منفذة هنا

`tests/PharmaLIMS.ReviewRegression` يحتوي **100 حالة**: 54 لتفسير PRM و46 للحساب
واللقطات والتحقق التاريخي. يربط ملفات الخدمات الإنتاجية مباشرة، دون نسخ منطق بديل
أو اعتماد على WPF/SQL أو حزم خارجية.

تم توسيع `tests/PharmaLIMS.DatabaseIntegration` بعقود المصادقة الفعلية، واختيار الدليل
المشترك المقفول، وحماية rowversion، ودقة ResultCFU. يختبر أيضًا الترحيلة الجديدة على
مخطط قديم مصغر ذي بيانات، وإعادة تشغيلها دون تغيير البيانات، ورفض تحويل يفقد الكسور.
تظل السلسلة الكاملة لقاعدة الأساس والترحيلات ضمن اختبارات التكامل القائمة.
سيناريوهات المصادقة الجديدة تحاكي تبدّل البيانات بين القراءة والإتمام؛ اختبار الجلسات
المتوازية ومسارات أزرار WPF مطلوب بصورة مستقلة.

لم يتوفر في بيئة التنفيذ `dotnet` أو `msbuild` أو Windows/WPF أو `sqlcmd`/SQL Server.
لذلك لا توجد نتيجة بناء أو ترحيل أو مصادقة تشغيلية أو طباعة مدعاة لهذه الحزمة.

## اعتبارات قبل النشر

الترحيلة تغير مخطط قاعدة البيانات، ولذلك الاستبدال ليس نسخ ملفات الواجهة وحدها.
لا تشغّل عملاء v259 بالتزامن مع v260. احتفظ بإعدادات الموقع خارج الاستبدال، واختبر
استعادة نسخة احتياطية قبل الترقية. الترحيلة لا تعيد كتابة النتائج التاريخية أو
توقيعاتها؛ يجب التعامل مع البيانات غير المتسقة بمراجعة وتصحيح محكومين.

الملف `Database/Verification/20260910_Review_Remediation_Verification.sql` للقراءة
والتشخيص فقط. كشف صف تاريخي لا يعني إصلاحه تلقائيًا أو نفي سلامته لمجرد غياب رقم إصدار الحساب.

سكربت بوابة الإصدار يتوقف الآن عند رمز خروج فاشل للأوامر الخارجية. التشغيل باستخدام
`-SourceOnly` أو `-SkipBuild` أو دون SQL لا يطبع إغلاقًا تشغيليًا مكتملًا.
